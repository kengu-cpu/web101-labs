# Web101 Labs - Week 01

##  Overview

This project is part of the Web101 course. The goal of this lab is to get familiar with basic web development tools such as Browser DevTools, VS Code, and GitHub, and to understand how HTTP requests work.

---

##  Objectives

* Learn how to use browser DevTools (Network tab)
* Understand HTTP request and response
* Create a basic HTML file
* Run a webpage in the browser
* Upload the project to GitHub

---

##  Tools Used

* VS Code
* Web Browser (Chrome / Edge)
* Git & GitHub
* Node.js (optional)

---

##  Project Structure

```
web101-labs/
└── week-01/
    ├── hello.html
    └── README.md
```

---

##  How It Works

1. Open a website and inspect it using DevTools (F12)
2. Go to the Network tab and reload the page
3. Observe different types of files:

   * HTML
   * CSS
   * JavaScript
   * Images
4. Click on the HTML file and check its Headers

---

##  Sample Code (hello.html)

```html
<!DOCTYPE html>
<html>
    <head>
        <title>Hello</title>
        </head>
        <body>
            <h1>Hello World</h1>
            <p>This is my fist webpage</p>
        </body>
        </html>
```

---

##  How to Run

* Open the `hello.html` file by double-clicking it
* It will open in your browser
